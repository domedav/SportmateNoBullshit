This is the open source reverse enginiered version of the sportmate app, that is essential for many gyms in hungary.

This app lets you access the web version of sportmate, to create your account or to log in, as well as allowes you to access your QR code.
Once you leave the app, only the qr code stays! No need for the large sized, telemetry filled, spyware thats given out to you. Use this app instead!
